Vectiq Marketplace

Modules for Vectiq, the all-in-one bot for Vector communities. Every module is one JSON file: commands, autoresponders and timers, and sometimes a little Python.

Dashboard: Marketplace → Browse → GetChat: !module get <id>Terminal: vectiq --import-module file.module.json

Make your own: start from the template or ask an AI with the prompt in CONTRIBUTING, then open a pull request. Vectiq checks each file against the checksum in catalog.json before it uses it. Modules marked “runs code” contain Python that runs on the bot's computer; Vectiq only installs them when its owner allows it.
